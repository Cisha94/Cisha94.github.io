The performance of AES TEST

2026年2月6日
1 minute read

##一、设计概述 本设计实现了一个基于AHB总线的RAM模块，数据位宽为128位，支持AHB协议中的基本读写操作。内部采用四块32位的BRAM实现128位数据存储，并集成AES-128CTR模式加密模块，实现数据的实时加密写入和解密读出。 主要端口如下：

端口名 方向 位宽 功能描述 HCLK 输入 1 AHB 系统时钟 HRESETn 输入 1 低有效异步复位 HSELBRAM输入 1 模块选择信号 HREADY 输入 1 总线就绪信号 HTRANS 输入 2 传输类型（IDLE/BUSY/NONSEQ/SEQ） HSIZE 输入 2 传输数据宽度（字节数） HWRITE 输入 1 写使能 HADDR 输入 AW:0 地址总线 HWDATA 输入 127:0 写数据总线 HREADYOUT输出 1 从设备就绪输出 HRESP 输出 1 响应类型（OKAY/ERROR） HRDATA 输出 127:0 读数据总线

##二、时序与控制逻辑 使用 negedge HRESETn 或 posedge HCLK 进行异步复位与同步控制。 通过 HWRITE_neg 和 done_encode_neg 边沿检测信号实现写操作与加密完成同步。 输出 HREADYOUT 由加密模块的 ready_encode 和 ready_decode 共同控制，确保数据准备就绪。 当模块被选中、总线就绪且传输类型为 NONSEQ 或 SEQ 时，传输有效。

assign trn_valid = HSELBRAM & HREADY & HTRANS[1]; 写数据流程： 1.写操作有效时，reg_wr_en 和 reg_haddr 在 HWRITE_neg 或 done_encode_neg 边沿锁存。 2.加密完成后，根据锁存的使能与地址将 ciphertext 写入对应 BRAM。 读数据流程： 读操作直接从 BRAM 中读出数据，通过 HRDATA_cipher 组合输出。
