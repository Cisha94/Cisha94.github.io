Hugo + GitHub Pages搭建个人博客

2025年12月5日
1 minute read

一、优缺点

Hugo + GitHub Pages是静态页面，优缺点十分明显： 优点 1）完全免费，GitHub Pages 免费托管，自定义域名也免费并且无流量费用； 2）因为Hugo生成的都是纯HTML，无需数据库查询，而且GitHub 全球 CDN 加速，所以访问速度很快； 3）超级稳定，只要GitHub不倒闭，你的博客就在，而且无需担心服务器维护、宕机等问题； 4）搭建简单。 缺点 5）动态功能受限，无法直接实习用户评论系统、文章点赞功能、用户登录系统等； 6）每次更新都需要本地编辑文章，并且等待（2到5分钟构建）。 不过总而言之，对于写个人博客和分享学习笔记是很好的选择。

二、搭建流程 

    1）安装必要的环境

1.安装Git

2.安装Hugo

注意下载如上图这个版本，不然容易报错 解压，把hugo.exe放到C:\Windows\System32
2）使用Git Bash操作 在桌面右键选择“Git Bash Here”，打开指令窗口，如下图： 然后输入hugo new site my_blog, 创建Hugo项目，输入cd my_blog, 进入my_blog文件夹，再输入git init初始化Git，接着添加主题。 可以在这个网站选择主题，这里以*[](https://github.com/CaiJimmy/hugo-theme-stack* 这个主题为例，输入git submodule add https://github.com/CaiJimmy/hugo-theme-stack themes/hugo-theme-stack themes/hugo-theme-stack安装主题,之后打开hugo.toml,修改内容：

baseURL = ‘https://你的用户名.github.io/’ languageCode = ‘zh-cn’ title = ‘我的个人博客’ theme = ‘ananke’

	然后在Git Bash输入hugo server -D，即可完成本地部署，可以在浏览器访问http://localhost:1313查看效果，对布局页面进行修改。

三、部署到GitHub Pages 

1. 本地编辑文章
2. git add .
3. git commit -m "update"
4. git push
5. 等待构建（2-5分钟）
